## Key design decisions

- **Read-only API usage.** RetroAchievements is used GET-only; there is no REST write/payload-contract model. `Pixel Grid JSON` plays the equivalent modularity role locally — one producer (Pixel Grid Builder), four interchangeable geometry consumers.
- **Gate 2/3 merges.** The standalone Auth component was folded into RA Console (its `GetConsoleIDs` call doubles as connectivity check + value-list populator). Mosaic kept 3 distinct components (different fabrication outputs) rather than merging into one parametric placer. Ingest kept Local Sprite Loader and Sprite Sheet Splitter decoupled (single-frame vs. multi-frame use cases).
- **Zero-padded subcategory numbering** (`01.` … `07.`) in `PluginUtilities.cs`, to avoid the ribbon-sort break that unpadded prefixes cause once a plugin reaches double-digit subcategories.
- **Gate 6 contract revision.** Ingest components (Local Sprite Loader, Sprite Sheet Splitter, RA Badges) all emit a shared `Pixel Colors` tree (one branch per row, nested under any per-frame/per-badge index) instead of raw image paths. Palette Quantizer consumes/produces that tree directly. Pixel Grid Builder's `Rows` input accepts either a Colour/hex tree or comma-separated hex row strings. The Pixel Grid JSON schema is `{bounds, pitch, thickness, palette, indices}` — palette deduplicated in first-seen order, `-1` marks a void/transparent cell. See dogfood F7 for the full change list.
- **ButtonComponent everywhere an HTTP call happens** (RA Console, RA Game Info, Find Game) — even though the API is read-only, this avoids firing live calls on every canvas recompute.
- **Never hardcode third-party data the plugin doesn't own.** Filament colors are the user's own real inventory, not a baked-in preset — Filament Library Loader reads them from a file on disk instead. Same reasoning kept a `Find Game` name→ID lookup from inventing fake search data: it hits the real `GetGameList` endpoint.
- **RA Game Info stays numeric-ID-only, by design.** Name-based lookup lives in a separate component (Find Game → GetGameList + client-side substring match) rather than teaching RA Game Info to guess — RA has no server-side title search endpoint.
- **RA Badges' `BadgeName` is a CDN resource ID, not a readable label** — the component now also surfaces `Achievement Title` (the real readable name) alongside the renamed `Badge Resource ID`, both pulled from the same achievement record it already parses.
- **Game-level artwork (RA Game Images) needs mandatory downsampling.** Box art / title screens are far higher resolution than achievement badges (300-600px+ vs ~64px) — voxelizing every literal pixel builds hundreds of thousands of tiny meshes and can hang/crash Rhino. `Max Dimension` (default 64) resizes before any pixel read.
- **Component signature changes need a fresh instance, not just a `.gha` reload.** Grasshopper does not retroactively re-run `RegisterOutputParams` on an already-placed component instance — inserting/reordering outputs (as happened to RA Badges and RA Game Info during this build) silently misaligns old wires on old instances. Always drop a fresh component after a signature change.
<!-- pr:end decisions -->

<!-- pr:begin limitations -->
## Known limitations

- **RA write endpoints** (set requests, comments, award writes) — out of scope; RetroVoxel is a read + local-fabrication tool.
- **`GetGameList` / `GetUserProgress` / `GetUserProfile` / Leaderboards / Tickets / Feed** — not used by any stated workflow; Ingest scope is Game + Achievement + Console catalog only.
- **No automated box-art aspect-ratio extraction** — Laser Standoff Stack's `Aspect Ratio` is typed in by hand; a future version could compute it from `ImageBoxArt`'s pixel dimensions automatically.
- **Multi-Material Interlock is a v1 simplification** — tags the whole mesh with its dominant filament match rather than generating true per-color interlocking dovetail geometry.
- **Palette Quantizer uses simple nearest-frequency quantization**, not a full median-cut/k-means algorithm.
- **Phase 12 (Rhino live test) was degraded** — no Grasshopper MCP bridge was configured this session; `demos/README.md` holds the manual build spec instead of pre-built `.gh` canvases.

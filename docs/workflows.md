# Workflows

What you can do with RetroVoxel:

- Fetch every achievement badge for a game and voxelize the whole set into individually-tagged
  plaques in one batch — see [Game badges to voxel](examples/game-badges-to-voxel.md)
- Split a local sprite sheet into frames and vary voxel extrusion height per frame — see
  [Sprite sheet extrusion](examples/sprite-sheet-extrusion.md)
- Quantize a tree of sprites or badges to a target filament color count and preview the closest
  real filament match before committing to fabrication — see
  [Sprite sheet extrusion](examples/sprite-sheet-extrusion.md)
- Turn any tabular color grid — hand-authored, from a spreadsheet, or sprite-derived — into Lego
  stud plates, Perler bead layouts, or LED matrix wiring, interchangeably — see
  [Tabular grid mosaic](examples/tabular-grid-mosaic.md)
- Size a laser-cut standoff stack to a game's real box-art aspect ratio instead of eyeballing
  dimensions — see [Box art standoff](examples/box-art-standoff.md)
- Check a RetroAchievements API key and browse the console catalog — see
  [Connection](examples/connection.md)

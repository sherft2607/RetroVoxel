# 01. Ingest

| [RA Badges](RA-Badges.md) | Downloads each achievement's badge image and its pixel colors |
| [Find Game](Find-Game.md) | Resolves a game name/substring to its numeric Game ID |
| [RA Game Images](RA-Game-Images.md) | Downloads a game's Icon/Title/Ingame/Box Art image and its pixel colors |

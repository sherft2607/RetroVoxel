# RetroVoxel

Computational design and physical fabrication toolkit for retro gaming pixel art, sprite sheets,
and mosaic geometry, for Grasshopper (Rhino 7 / Rhino 8 Windows / Rhino 8 Mac). Pulls game and
achievement data from the [RetroAchievements Web API](https://retroachievements.org/API/) and turns
any pixel-art source — a local sprite sheet, a downloaded achievement badge, or a hand-authored
color grid — into voxel meshes, mosaic layouts, and laser-cut fabrication geometry.

## Install

Search "RetroVoxel" in Rhino's `_PackageManager`.

## Components by tab

| Subcategory | Components |
|---|---|
| 01. Ingest | Local Sprite Loader, Sprite Sheet Splitter, RA Game Info, RA Badges, Find Game, RA Game Images |

| 03. Grid | Pixel Grid Builder |
| 04. Fabrication | Voxel Mesh Shell, Multi-Material Interlock, Laser Standoff Stack, Achievement Attribute Bridge |
| 05. Mosaic | Lego Stud Plate, Perler Bead Grid, LED Matrix Mapper |
